# ImageProcessor 简化改进报告

## 简化概述

对 `ImageProcessor` 的多线程扫描逻辑进行了全面简化，移除过度复杂的锁机制和全局状态，提升代码可读性和性能。

## 主要简化内容

### 1. 移除复杂锁机制

**简化前**:
- `_scan_lock` 全局锁 (10个使用点)
- `albums_lock` 局部锁
- `scanned_lock` 局部锁
- 多层嵌套的锁，容易死锁

**简化后**:
- 移除所有全局锁
- 只保留一个 `albums_lock` 保护结果列表
- 锁使用点从 10 个减少到 1 个

### 2. 简化全局状态管理

**简化前**:
```python
_scan_lock = threading.Lock()
_cancel_flag = False  # 全局可变状态
_scanned_count = 0    # 全局计数器
_max_albums = 1000    # 全局限制
```

**简化后**:
```python
# 无全局状态
scanned_count = 0  # 局部计数器
```

**改进**: 移除了所有类级别的可变状态，使方法成为纯函数，更易于测试和调试。

### 3. 简化智能分组算法

**简化前**:
- 复杂的多层分组逻辑
- 名称相似度计算（O(n²)）
- 快速模式切换
- 作者分组 + 名称分组

**简化后**:
- 只保留作者分组（提取方括号内的信息）
- 移除复杂的名称相似度计算
- 移除了智能分组的快速模式分支

**影响**: 分组精度略有降低，但性能提升且代码更简洁。

### 4. 简化进度回调

**简化前**:
- 每10个项目更新一次进度
- 多线程下可能竞争

**简化后**:
- 每20%或每5个项目更新一次
- 主线程更新，无竞争
