# Local Gallery · 设计契约

本文件定义界面设计的决策权限、体验与交互原则、Atelier 设计系统规范、无障碍与大库性能底线，以及界面验证方法。产品定位、路由与功能语义以 [PRODUCT.md](./PRODUCT.md) 为准；模块实现与数据边界见 [ARCHITECTURE.md](./ARCHITECTURE.md)；快捷键明细见 [SHORTCUTS.md](./SHORTCUTS.md)。

---

## 1. 决策权限与不变边界

### 1.1 设计授权

执行界面优化或重设计时，可按用户目标重做页面骨架、板块顺序、布局、组件与交互；旧截图、旧网格列数与既有几何断言仅作为现状参考，不构成设计限制。**设计系统本身（§4 的语义 token、字号阶梯、圆角、组件形态与容器变体）是全站基石**，修改时须同步更新本契约与审计基线。

若界面改动改变了入口职责或路由，须在实现与实机验证完成后于同一改动中同步更新 [PRODUCT.md](./PRODUCT.md)。

### 1.2 必须守住的底线

任何视觉或交互重设计都不得：

- 删除既有功能或破坏旧书签重定向；
- 改变 API 数据语义、重置用户偏好或绕过访问控制与路径安全校验；
- 对原始媒体目录执行任何写操作；
- 降低无障碍可用性（§5）或牺牲大库渲染与首屏性能（§6）；
- 通过跳过或删除有效断言来制造检查通过。

## 2. 体验原则

1. **媒体与结果优先**：每屏先呈现核心内容（照片、作品、检索命中项），统计读数、说明与技术状态降级或按需展开，不挤占首屏。
2. **降低导航层级**：能在当前页完成的操作不额外跳页；深链进入的页面具备确定上下文与返回落点。
3. **保持来源上下文**：面包屑、所属文件夹/作品、筛选与排序条件保持可见；适合分享或恢复的状态（目录、筛选、页签、视图）同步至 URL。
4. **双工作台各有语气**：照片侧为冷静展陈墙（暖白 / 曜石暗色），漫画侧为暖铜赭书架（竖版书封与装订边）；两侧共用无障碍、反馈与导航机制。
5. **状态诚实**：严格区分加载中、空结果、未分析、部分失败与完整失败；不得在加载中途用 `0` 冒充真实结论，所有计数与时间口径清晰一致。
6. **写操作可辨认、留退路**：精选、收藏、人物合并、相似组决定与危险清理明确说明影响范围与「不修改原始文件」；导致条目离开当前视图的操作提供可撤销提示条。
7. **真实照片优先**：相册、文件夹与主题均以真实媒体占位，不用大片空白灰块或示意图替代；缺失时明确告知原因与下一步入口。
8. **全输入方式平等**：鼠标、触控、键盘与读屏均可完整完成核心任务，不将悬停作为唯一入口，状态不只靠颜色区分。
9. **克制与清晰**：Atelier 将主内容置于独立画布中，每屏聚焦一个主对象；页头动作集中在右侧（常规最多两个），区块间以留白分隔，列表内用细线分隔。

## 3. 交互契约

- **搜索范围明确**：名称搜索与画面/文字内容搜索分属不同能力，界面必须标明当前范围，不暗示二者等价。
- **对象与动作全站一致**：资源级「收藏」与照片级「精选照片」的名称、图形与页签严格区分；同一动作在全站保持一致文案与反馈。
- **筛选与分组不静默冲突**：相册页原始墙筛选与智能分组互斥；进入分组时显式清除冲突筛选并给出提示，回到全部照片不意外复活已结束的条件。多组并排筛选控件须带可见标签。
- **系统自动纠错不污染历史**：分组 ID 失效等自动回退使用 `replace` 改写当前地址；用户主动切换正常入栈，确保前进/后退不陷入死循环。
- **局部失败不推倒整页**：分页失败保留已加载内容并暂停自动续页，由用户显式重试；单一区块失败不影响同页其他可用区块。
- **浮层与模态焦点完整**：模态对话框与抽屉实施焦点陷阱与背景锁滚，`Esc` 逐层关闭并将焦点归还触发控件。
- **时间与少量内容呈现**：推断时间必须标注来源，仅文件修改时间不混入年份；少量精选照片（1–4 张）不强行裁切凑行，改为原比例单幅居中陈列。
- **快捷键单一来源**：键盘行为严格对齐 [SHORTCUTS.md](./SHORTCUTS.md)，不覆盖文本输入与浏览器常用组合键。

## 4. Atelier 设计系统

### 4.1 色彩角色与样式分层

色值集中定义于 [`frontend/src/styles/tokens.css`](../frontend/src/styles/tokens.css)，角色清单见 [`frontend/src/styles/tokens.ts`](../frontend/src/styles/tokens.ts)；组件仅引用语义 token 或 Tailwind 语义类，不在组件内硬编码 hex 颜色：

| 层级 / 角色 | Token | 说明 |
| --- | --- | --- |
| 表面层级 | `--app`、`--canvas`、`--raised`、`--sunken`、`--sunken-strong`、`--media` | 应用外壳、独立画布、浮层卡片、输入/分组槽底与媒体占位底 |
| 文字层级 | `--ink`、`--ink-2`、`--ink-3` | 主正文、次要信息、辅助计数（明暗双主题正文对比度 ≥ 4.5∶1） |
| 线条与交互 | `--line-subtle`、`--line`、`--line-strong`、`--hover`、`--pressed`、`--selected` | 分隔线与交互反馈 |
| 主操作与焦点 | `--primary` / `--on-primary`、`--accent` / `--accent-text` / `--accent-soft` | 照片主色为中性炭黑/象牙白；信号蓝 `--accent` 专用于键盘焦点环（对比度 ≥ 3∶1）、选态与设置开关 |
| 漫画工作台重映射 | `:root[data-mode="comic"]` 覆盖 `--primary`（浅 `#8a4f2d` / 深 `#d9a074`）、`--on-primary`、`--brand-soft`、`--cover-band`、`--book-page-edge` | 仅通过语义重映射切换暖铜赭气质，不引入第二套颜色命名体系 |
| 语义状态 | `--success`、`--warning`、`--danger`、`--favorite` | 配合图标与文案使用 |
| 暗场舞台 | `--theater-bg`、`--theater-surface`、`--theater-fg`、`--theater-accent`（`#d9a074`） | 大图预览与漫画阅读器恒为暗场，独立于应用明暗主题 |

### 4.2 字体、圆角、阴影与动效

- **字体与数字**：内置 `@fontsource-variable/inter` 可变字体（同源加载，启用等宽数字与字形特性），中文回退至系统界面字体（`Segoe UI Variable Text` / `PingFang SC` / `HarmonyOS Sans SC` / `MiSans` / `Microsoft YaHei UI`）。
- **字号阶梯**：显示标题 `clamp(28px, 1.2vw + 16px, 40px)`、页面标题 `24px`、节标题 `17px`、分组标题 `15px`、正文 `14px`、控件标签 `13px`、辅助说明 `12px`；单屏最多使用 4 档字号，可见文字不小于 `12px`。
- **圆角阶梯**：照片瓦片 `4px`（`--r-tile`）、徽标 `6px`（`--r-sm`）、控件 `8px`（`--r-md`）、卡片/浮层 `12px`（`--r-lg`）、画布/模态 `16px`（`--r-xl`）。
- **间距与阴影**：页边距 `clamp(16px, 2vw, 40px)`，区块间距 `clamp(32px, 3vw, 56px)`；阴影分 `--e1`（输入/卡片）、`--e2`（菜单/浮层）、`--e3`（模态对话框，配合半透明遮罩）。
- **动效时序**：悬停/按下 `120ms`、控件切换 `180ms`、抽屉/浮层 `280ms`、页面/大图转场 `360ms`；系统开启「减少动态效果」时将位移与缩放退化为 `120ms` 透明度过渡。

### 4.3 组件形态与五类容器变体

- **控件尺寸**：按钮高度分 `32px` / `36px` / `44px`，标签 `13px`；桌面独立交互目标 ≥ `32×32px`，触摸命中区 ≥ `40×40px`。
- **键盘导航原语**：分段控件支持方向键并跳过禁用项；工具条支持方向键与 `Home`/`End`；搜索框在 IME 组字期间回车继续选词，`Esc` 先清空再失焦。
- **容器变体（`Page`）**：`standard` / `system`（最大 `1440px`）、`focused`（最大 `760px`）、`gallery` / `workspace`（占满画布或宽屏最大 `2400px`）。主内容在画布内滚动，虚拟列表绑定该滚动容器，吸顶工具条高度驱动月份段头等次级吸顶偏移。

### 4.4 外壳与顶栏

- **桌面端（≥ 1024px）**：左侧栏宽 `240px`（折叠态 `72px`），画布上/右/下内缩 `8px`、圆角 `16px`。顶栏高 `44px`（无返回与局部搜索且未滚动时与内容共享首行，滚动后显露收缩标题与半透明底色）。
- **窄屏端（< 1024px）**：画布铺满视口，顶栏高 `48px` 并提供搜索按钮，底栏高 `64px` 承载至多 4 个主入口与「更多」抽屉；进入沉浸式阅读器或大图预览时隐藏底栏。
- **命令面板**：最大宽 `640px`，桌面距顶 `12vh`，统一承载名称搜索、画面与文字搜索、最近 8 条记录、快捷导航与命令。

### 4.5 关键页面视觉规范

- **照片时间线与回忆**：回忆按年份 4∶5 封面横向展开（低于 760px 折叠为摘要触发底部面板）；月份头随滚动吸顶，稀疏月份支持同行拼排。
- **相册与文件夹网格**：照片相册使用 `4∶3` 封面，文件夹为单张真实封面配双层叠影与小图标；列间距 `24px`、行间距 `32px`，列宽随视口从 `220px` 增至 `260px` / `300px`；列表行高 `56px`（封面 `48px`）。宽屏目录面板宽 `264px`，窄屏使用左侧抽屉。
- **发现与搜索**：宽屏人物与地点按 `8∶4` 并排，窄屏纵向排列；年份横带进入视口后懒加载封面；搜索结果在顶栏直接编辑查询词。
- **珍藏与相似整理**：珍藏三页签共用 `standard` 左缘网格线；1–4 张精选按原比例居中单幅展陈（上限 `420×560`），5 张起切瀑布流；最近浏览使用 `72px` 日期分组行。相似照片在 ≥ `1280px` 默认双栏（组列表宽 `360px`、行高 `72px`），审阅主操作用细线按钮避免大面积色块干扰对比。
- **设置与任务中心**：`system` 容器（最大 `1440px`），四个分区各自按 `6∶6` 或 `7∶5` 双栏排布并在窄屏按阅读序堆叠；危险操作确认框默认聚焦「取消」按钮。
- **漫画书架与阅读舞台**：书封恒为 `2∶3` 竖版并保留书脊装订暗边与精装书口（`--book-page-edge`），书名压条（`--cover-band`）置底保证在白底封面上对比度 ≥ 8∶1；书架最小列宽 `160px`（宽屏 `200px`）。阅读舞台占满暗场，顶底工具栏悬浮覆盖并在显隐切换时保持画面几何稳定；阅读列按 `≥960px` / `640–959px` / `<640px` 三档渐进收纳次级控件。

## 5. 无障碍与响应式底线

- 全部核心路径可仅凭键盘完成，焦点环始终清晰可见；控件具备准确的语义角色、可访问名称与状态。
- 文本对比度满足 WCAG AA（正文 ≥ 4.5∶1，图形与焦点 ≥ 3∶1）；不单独依靠颜色、悬停或动效传达信息。
- 完整支持浏览器缩放、窄视口（含 `320px`/`360px`/`390px` 竖屏与横屏）、触摸操作、软键盘避让（`--keyboard-inset`）与 `prefers-reduced-motion`。

---

## 6. 大库性能底线

- 列表与照片墙按需分页和虚拟化（`react-virtuoso` / 视口窗口裁切），首屏不下载全库媒体；图片按实际槽位宽度与 DPR 经 `RenditionImage` 选取合适渲染档位。
- 服务端状态由 TanStack Query 管理，客户端 UI 偏好由 Zustand 管理，不复制第二份长期媒体库或收藏/历史数据源。
- 生产构建首屏静态资源预算受 `audit:size` 守护：在线首屏 HTML+JS+CSS 传输上限 `120 KiB`、本地字体独立上限 `80 KiB`；CI 构建产物入口总大小上限 `420 KiB`。

## 7. 验证方法

### 7.1 界面与跨层验证

每轮代码改动后，须基于当前源码重新构建并启动应用，在明暗双主题与宽窄视口下验证实际 API、交互与截图（临时截图保存至 `frontend/.smoke/<任务>/`，不提交入仓）。

在 `frontend/` 目录下按需执行：

| 命令 | 校验内容 |
| --- | --- |
| `npm run audit:layout` | 校验侧栏宽度（`240/72px`）、画布内缩与圆角、顶栏（`44/48px`）、底栏（`≥64px`）、容器上限、横向溢出、最小字号（`≥12px`）、触控目标（`≥32px` / 触摸 `≥40px`）与抽屉焦点陷阱 |
| `npm run audit:contrast` | 校验明暗主题下文字与图形对比度（支持 `palette` 伪路由检查命令面板） |
| `npm run audit:crash` | 相册与照片墙反复切换与滚动的崩溃探针 |
| `npm run audit:size` | 首屏静态载荷体积审计（传入 `-- --dist` 可在离线/CI 直接核验构建产物） |
| `npm run shot` / `npm run shot:el` | 批量截取多路由、多主题、多视口或单元素页面截图 |
| `npm run test:e2e` | 独立临时媒体库的全栈 Playwright 端到端测试 |

### 7.2 审计与截图脚本环境变量

以下变量仅用于控制验证脚本，**不覆盖**后端 YAML 运行配置：

| 变量 | 用途 |
| --- | --- |
| `LG_BASE` | 目标服务地址，默认 `http://127.0.0.1:5173` |
| `LG_PAGES` | 逗号分隔的路由列表，支持 `album`、`viewer`、`reader`、`tag`（对比度审计另支持 `palette`）等伪路由 |
| `LG_THEMES` | 主题列表，默认 `light,dark` |
| `LG_VIEWPORTS` | 视口尺寸列表，如 `390x844,1440x900` |
| `LG_TOUCH` | 设为 `1` 开启触摸设备模拟 |
| `LG_DPR` | 设备像素比，默认 `1` |
| `LG_ORIENTATION` | `portrait`、`landscape` 或 `both` |
| `LG_VIEWMODE` | `grid` 或 `list` |
| `LG_FULL` | 是否整页长截图 |
| `LG_CRASH_VISITS`、`LG_CRASH_ALBUM`、`LG_CRASH_VIEWPORT`、`LG_CRASH_MOCK_THUMBS` | 崩溃探针运行参数 |
| `LG_W`、`LG_H`、`LG_SCALE`、`LG_STATE` | 元素截图脚本参数 |

### 7.3 纯文档改动验证

仅修改文档时，核对 Markdown 格式、本地文件路径与章节锚点链接、以及文档内容与当前源码的一致性，不新增业务测试。
