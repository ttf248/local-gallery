# Local Gallery v2.0.0

这是 Go + React 新架构的首个正式版本。

## 主要变化

- 后端迁移为 Go 1.24 + Fiber v2，前端使用 React 18 + Vite 5 + TypeScript；
- 单进程、单端口提供 API 与前端静态资源；
- 支持多媒体根目录、资源 ID、扫描缓存、缩略图缓存和视频处理管线；
- 提供 Linux、Windows、macOS 的 amd64/arm64 发布包及 SHA256 校验文件。

## 迁移说明

`v1.x` 是旧 Python/PyInstaller 架构，与本版本的配置文件、启动方式和运行时边界不同。请从 `backend/config.example.yaml` 复制新的配置文件，按当前 `mediaRoots` 契约重新配置；不要把旧版本缓存目录或启动参数直接当作兼容接口。

## 启动

解压对应平台压缩包，复制并编辑 `config.example.yaml` 为 `config.yaml`，设置媒体根目录后运行包内的 `local-gallery`（Windows 为 `local-gallery.exe`）。
