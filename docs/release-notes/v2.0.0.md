# Local Gallery v2.0.0

这是 Go + React 新架构的首个正式版本。

## 主要变化

- 用一个本机进程浏览照片、漫画和视频，状态保存在本机目录。
- 照片支持按相册、时间、地点、人物和精选浏览，可执行中文语义搜索、以图搜图和相似照片整理。
- 漫画支持多种翻页方式、章节目录、阅读进度恢复、封面选择与作品预览。
- 提供 Windows x64 便携 ZIP，以及 Linux 和 macOS 的 x64、Arm64 压缩包。各包的 SHA256 收录在 `SHA256SUMS`。

## 迁移说明

从 v1.x 升级时，将 v2 解压到新目录，再到「设置与任务 → 媒体库与服务」添加原有照片和漫画目录。

## 启动

Windows 用户完整解压 `local-gallery-v2.0.0-windows-amd64-portable.zip` 后双击 `start.bat`，在浏览器访问 `http://127.0.0.1:8080`。包内已有 Python、FFmpeg、Chinese-CLIP、RapidOCR、YuNet 和 SFace，核心功能可以离线使用。推理优先使用支持 DirectML 的 GPU，未检测到可用 GPU 时转用 CPU。相册封面审美和 Buffalo_m 权重可通过 `download-extra-models.bat` 按需从各自上游获取。

macOS 和 Linux 用户把 `config.example.yaml` 复制为 `config.yaml` 后运行 `./local-gallery --config ./config.yaml`。
