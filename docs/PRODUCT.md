# Local Gallery · 产品契约

本文件是产品结构的唯一真相源，定义产品定位、双工作台信息架构、路由表、核心页面职责、功能语义、关键用户路径与外壳导航规则。视觉系统与交互验收见 [DESIGN.md](./DESIGN.md)，系统模块与实现边界见 [ARCHITECTURE.md](./ARCHITECTURE.md)，接口字段见 [API.md](./API.md)，协作规范见 [AGENTS.md](../AGENTS.md)。

> **契约范围**：本文件约束「有哪些入口、各自回答什么问题、承载什么功能语义」。具体页面骨架、板块排布、组件形态与配色方案属于 [DESIGN.md](./DESIGN.md) 的决策权限；当新交互改变入口职责或路由时，应在验证后于同一改动中同步更新本文件。

## 1. 产品定位与核心原则

Local Gallery 是单用户、本机优先的私人影像空间，将本地照片、视频与漫画组织成**能看、能找、能探索、能整理、能接着读**的统一界面。

- **私人本机优先**：不提供多账号、云同步、在线分享或协作能力。
- **原始媒体只读**：绝不移动、改名、删除或覆盖任何原始照片、视频与漫画文件；所有收藏、精选、进度与分析修正均独立保存在应用状态目录中。
- **动词导向**：产品能力按「**观看 · 寻找 · 探索 · 整理 · 连续阅读**」组织；不直接服务内容消费的系统能力（任务调度、缓存、服务配置）统一收拢至系统层「设置与任务」。

### 双工作台互斥设计

配置中的每个媒体根目录具有且仅有一种内容属性：**照片（`photo`）**或**漫画（`comic`）**。属性由根目录显式决定，目录下的文件夹与相册自动继承，不按图片数量推断，也不提供单本归类操作。

两个工作台相互独立、互不混排，菜单、列表、计数单位、状态与视觉材质各自成套：

| 维度 | 照片工作台（`/photo`） | 漫画工作台（`/comic`） |
| --- | --- | --- |
| 核心动词 | 观看、寻找、探索、整理 | 连续阅读、找书 |
| 内容单位 | 相册（张） | 卷（页） |
| 中间目录 | 文件夹 | 作品（顶层）/ 系列（嵌套） |
| 状态模型 | 浏览历史（落点在相册，不记照片位置） | 阅读进度（精确到页）、在读 / 已读 / 未读 |
| 专属能力 | 时间线、那年今日、精选照片、人物、足迹、主题、内容搜索、相似整理 | 继续阅读、未读队列、作品元信息与简介、沉浸式暗场阅读器 |

全局收藏与浏览历史在后端共用同一份持久化数据，前端按当前工作台过滤展示，不呈现跨侧统计提示。**「本侧不可见」不等于「资源失效」**——例如仅含漫画的标签被收藏后，在照片侧清理失效收藏不得将其删除。

## 2. 信息架构

### 2.1 照片工作台

照片工作台包含**四个一级入口**（分组「浏览」）与**一个次级入口**（分组「整理」）：

| 分组 | 入口 | 路由 | 回答的问题 | 核心内容 |
| --- | --- | --- | --- | --- |
| 浏览 | **照片** | `/photo` | 我现在想看点什么 | 按拍摄证据排列的全库时间线、「那年今日」回忆照片带、「接着看」 |
| 浏览 | **相册** | `/photo/library` | 照片在磁盘上怎么组织 | 真实目录层级网格/列表、按需展开的目录树抽屉、面包屑同级切换 |
| 浏览 | **发现** | `/photo/explore` | 怎样换个维度找到它 | 内容搜索入口 + 人物、地点（足迹）、时间（年份）、主题（智能相册）预览 |
| 浏览 | **珍藏** | `/photo/me/:tab` | 我留下的和看过的 | 三个独立页签：精选照片（`picks`）、收藏（`favorites`）、最近浏览（`recents`） |
| 整理 | **相似照片** | `/photo/similarity` | 哪些重复或连拍需要挑出代表 | 完全重复、近似副本、连拍逐组审阅（写操作，降为次级入口） |

四个一级入口职责严格正交：**照片**给内容、**相册**给结构、**发现**给维度、**珍藏**给个人数据；同一类内容不在多个入口重复堆叠。

### 2.2 漫画工作台

漫画工作台拥有独立的导航与状态体系，不套用照片侧页面骨架：

| 分组 | 入口 | 路由 | 回答的问题 | 核心内容 |
| --- | --- | --- | --- | --- |
| 漫画 | **首页** | `/comic` | 我要接着读哪一本 | 继续阅读（当前在读 + 在读队列）、未读精选、最近阅读 |
| 漫画 | **书架** | `/comic/library` | 库里有哪些作品与卷 | 作品、系列与散卷一览、年份次级筛选、一步「继续读」 |
| 漫画 | **我的** | `/comic/me/:tab` | 我留下的和看过的 | 三个独立页签：收藏（`favorites`）、最近阅读（`recents`）、在读（`reading`） |
| 漫画 | **未读** | `/comic/unread` | 还有哪些书没翻开 | 待办队列，默认按作品分页（可切按卷），支持整部标已读与撤销 |

### 2.3 系统层（「设置与任务」）

两个工作台在侧栏底部「本机」组（及窄屏「更多」抽屉）共用单一入口「设置与任务」。有运行、暂停或失败任务时，侧栏状态摘要可直接进入「分析与计划」。四个分区各自拥有独立路由，浏览器前进/后退可切换分区，已访问面板保留未提交草稿：

- **通用与阅读**（`/settings/general`）：外观主题、侧栏导航项可见性、照片与漫画阅读偏好、应用版本与快捷键入口；服务端偏好读取失败时仍可调整本地偏好。
- **分析与计划**（`/settings/tasks`）：顶部常驻状态摘要（运行态、排队数、暂停/继续/取消/失败重试与跳过的已知解析失败数），其下按全库通用 / 照片相册 / 漫画书架分组选择模块、查看增量/全量规模预估、使用照片或漫画场景预设、配置每日计划、硬件方案（GPU 优先 / CPU）、人脸模型切换、智能相册全库刷新及任务记录（默认展示前 8 条，可展开全部与每条任务产物）。
- **数据与存储**（`/settings/storage`）：磁盘占用、媒体库索引与扫描告警、文件变化实时监听开关、派生缓存清理与重建、本机绝对路径（受回环保护）、失效收藏与历史维护，以及 10 类本机状态的导出与预览/分项恢复。
- **媒体库与服务**（`/settings/server`）：媒体根目录与内容属性、扫描排除规则、缓存策略、本地/局域网访问控制、漫画公开元数据匹配及运行参数（受本机回环访问门禁保护）。

## 4. 核心页面职责

### 照片页（`/photo`）

- **全库拍摄时间线**：单张媒体独立取证（`EXIF 拍摄时间 > 文件名日期 > 有效目录日期 > 文件修改时间`），绝不把相册代表日期套给单张照片，也不给仅年份的证据虚构一月一日；仅含文件修改时间的媒体归入末尾「日期未知」段，不混入任何年份。
- **可定位、可恢复**：年、月、媒体类型、时间来源与日期精度实时写入 URL；精确到日/仅年月按月分段，仅年份按年分段；段头常驻推断/精度标注，统计明细收于可展开面板。首屏失败区分断网、库变更与服务端错误；分页失败保留已加载照片并停止自动续页，由用户显式重试（游标失效时从头重取）。
- **「那年今日」与「接着看」**：回忆照片带按浏览器本地日期优先取往年同月同日（不足时按月日距离补足，最多 8 张，矮屏默认折叠），不命中时不占位；「接着看」收纳在标题行，不抢占时间线主视觉。

### 相册页（`/photo/library`）与相册照片墙（`/photo/albums/:id`）

- **真实目录结构**：界面对中间目录一律称「文件夹」（不暴露服务端内部词「集合」）。目录树按需展开（默认仅展开当前路径链路、可单独折叠与按名搜索），面包屑支持同级快速切换与逐级返回父级。
- **封面与卡片语义**：照片相册与文件夹在每次进入页面时从审美入选项中抽取稳定封面（手设封面固定展示）；文件夹使用单张封面配叠影与小图标区分，避免在封面上叠加常驻黑标签。目录、排序、筛选与视图存入 URL，标题与计数口径与当前视图一致。
- **相册照片墙与分组面板**：
  - 筛选（拍摄月区间、人物、行政区、精选、合照/相似、折叠相似组）由服务端作用于整本相册，并返回未参与筛选的缺失计数。
  - 智能分组（精选推荐、时间、地点、人物、场景）是同一本相册的观察视图，不改动原始文件。进入具体分组时明确结束与之冲突的墙面筛选并提示用户；系统自动纠错（分组失效回退全部照片）使用 `replace` 改写地址，不污染浏览器历史。
  - 分组空态严格区分「未分析 / 有失败项 / 无分组 / 模块不可用 / 未启用人物分析」，每种给出对应的下一步操作。

### 发现页（`/photo/explore`）与搜索

- **四维独立呈现**：人物（候选脸头像，已命名与待确认分栏）、地点（离线城市卡片）、时间（与 `/photo` 共用单张证据口径的年份带，点击直达 `/photo?year=YYYY`）、主题（少量跨相册精选主题）。各段独立加载、独立报错与重试，缺分析结果时说明原因及入口。
- **两档搜索分离**：
  - **名称搜索（`scope=name`）**：检索相册、文件夹、作品、卷与标签，结果按命中理由分组（完全同名 / 开头相同 / 名字包含 / 标签命中 / 路径命中）。
  - **画面与文字搜索（`scope=content`）及智能搜索专页（`/photo/semantic`）**：融合 Chinese-CLIP 语义检索、RapidOCR 文字检索、以图搜图与结构化筛选；区分「请求失败」「模型未就绪或未建索引」「确实无匹配」三种无结果状态，不伪装成零结果。

### 珍藏（`/photo/me/:tab`）与相似照片整理（`/photo/similarity`）

- **珍藏三页签**：精选照片（1–4 张采用原比例单幅居中陈列，5 张起采用自然比例瀑布流，图下仅展示来源相册与拍摄日期、不显示文件名）、收藏（资源级卡片，明确标出相册/文件夹/标签类型）、最近浏览（仅展示相册与上次浏览时间）。单张移出精选提供即时撤销。
- **相似照片与连拍**：分「完全重复（内容哈希）」「近似重复（感知哈希 + 可选语义复核）」「连拍同场景（时间窗口 + 相似度，不视作重复）」三类，按「待处理 / 已处理 / 已忽略」三档待办管理。宽屏默认双栏逐组审阅，窄屏默认网格进入审阅舞台；标记、忽略与批量操作均提供按各组原状态精确还原的撤销能力（并发冲突时如实提示，不谎报成功）。

### 漫画首页（`/comic`）、书架（`/comic/library`）与阅读器（`/comic/read/:albumId`）

- **漫画首页**：严格按「继续阅读 → 未读 → 最近阅读」排序；无续读内容时不占空位；库内已有卷但尚未开始阅读时引导进入书架。
- **书架与作品页**：顶层分段陈列作品与散卷，使用规范书名（支持按原目录名、拼音别名或作者搜索）；多根时才显示来源标记；作品卡直达当前在读卷的「继续读」。作品详情头展示总封面、规范书名、作者、题材、卷页数、大纲与正篇/番外筛选，支持人工编辑、恢复自动识别与从任一卷选图设为总封面。
- **沉浸式阅读器**：脱离外壳铺满暗场，支持单页、连续滚动与双页并排（默认首张封面单列，宽跨页图自动单页）、LTR / RTL 翻页、章节目录与页码缩略图抽屉；进度仅按实际可见且已加载的最大页号保存，跨卷沿作品顺序推进，首尾不环绕。

## 5. 功能语义与术语表

### 5.1 统一术语表

前端文案唯一真相源位于 [`frontend/src/utils/workbench.ts`](../frontend/src/utils/workbench.ts)：

| 概念 | 照片侧称呼与单位 | 漫画侧称呼与单位 | 说明 |
| --- | --- | --- | --- |
| 媒体根目录 | 媒体目录（个） | 媒体目录（个） | 配置项 `{ path, kind }`，决定内容属性 |
| 中间目录（服务端内部称集合） | 文件夹（个相册） | 作品 / 系列（卷） | 界面上不出现「集合」一词 |
| 叶级目录 | 相册（本；内含张） | 卷（卷；内含页） | 漫画侧统一称「卷」，不混称「相册」 |
| 方括号标签 | 标签（个相册） | 标签（卷） | 解析自目录名 `[标签]`，≥2 本形成智能集合 |
| 资源级收藏 | 收藏（项） | 收藏（项） | 标记相册、文件夹、作品、卷或标签 |
| 照片级精选 | 精选照片（张） | 无 | 仅照片侧，独立存储于 `state/picks.json` |
| 访问历史 | 最近浏览（本） | 最近阅读（卷） | 落点均为相册 / 卷 |
| 阅读进度 | 无 | 在读 / 已读 / 未读 | 仅漫画侧，精确到页 |

### 5.2 核心语义边界

- **收藏 vs 精选**：两套独立存储与视觉图形，互不覆盖、互不清理；照片级留存用「精选照片」，容器级留存用「收藏」。
- **浏览历史 vs 阅读进度**：照片浏览不记录「读到第几张」，「接着看」回到上次翻看的相册；漫画记录页码并派生在读/已读/未读，「继续阅读」回到上次阅读页。
- **原始目录 vs 智能分组**：原始目录是磁盘事实；主题、人物、足迹、相似分组均是可重建派生视图，永不修改源文件。用户的改名、合并、隐藏、封面与审阅决定写入 `state/`，重建索引后依然保留。
- **日常浏览 vs 高级整理**：浏览仅产生自动的访问历史与阅读进度；精选、收藏、相似审阅、人物合并拆分、标记读完与封面覆盖属于写操作，明确提示改动对象与撤销/只读边界。
- **分析派生口径**：
  - **人物分组是候选，不是身份确认**：分为「常见人物」（已确认或 ≥3 张且含普通照片）、「待确认匹配」（附互证照片与低/中/高中文风险原因，须人工确认合并）与「合照候选」（仅在合照中出现）。未改名分组按展示序编号（「人物 1」「人物 2」），改名后固定且不占号；支持独立「精选人物头像」任务挑选清晰正脸。
  - **智能相册主题**：精选推荐综合时间、地点、人物与场景多维证据，卡片呈现证据维度，质量分仅用于后端排序不上屏；证据不足的照片留在原始照片墙，不强行归入「其它」。
  - **足迹与位置**：基于离线省市区三级边界，不请求外部地图；点位按粗网格聚合下发，行程按可配置间隔（默认 14 天）切分，到访按日历日间隔 ≤2 天归并；界面明确说明基站/网络定位可能存在百米级误差。

## 6. 关键用户路径

1. **观看（随手看照片）**：进入 `/photo` 时间线 → 点击打开大图预览 → 左右翻页（支持跨分页连续加载）→ `Esc` 退出回到墙上原位并归还焦点；浏览历史记入来源相册。
2. **寻找（按时间或内容找回照片）**：在 `/photo` 展开「那年今日」或按年月/来源筛选，或经命令面板 / `/photo/semantic` 用自然语言、文字或参考图检索 → 打开大图 → 点击标题直达来源相册。
3. **连续阅读（漫画续读）**：切换至漫画工作台 → `/comic` 首页点击「继续阅读」→ 阅读器恢复至上次页码 → 翻页至末页出现收尾界面（有下一卷继续，末卷明确告知）→ 退出返回来源或所属作品。
4. **探索（找人与找地点）**：进入 `/photo/explore` → 进入「人物」查看候选头像并命名/合并/拆分，或进入「足迹」按时间跨度展开行程与地点到访照片。
5. **整理（筛选重复与连拍）**：进入 `/photo/similarity` → 逐组对照质量指标与并排原图 → 指定代表照片 → 标记已处理或忽略（支持精确撤销）→ 批量将代表照片加入精选。

## 7. 外壳、导航与返回规则

- **工作台切换与导航**：桌面侧栏顶部提供工作台切换菜单（窄屏位于「更多」抽屉），切换同步写回 `appMode` 偏好并导航至目标工作台首页。除各工作台首页固定显示外，其余主入口可在设置页按 `navEntries.ts` 开关显示；窄屏底栏最多显示 4 个内容入口，其余收进「更多」。
- **三级安全返回规则（`useSafeBack`）**：
  1. 应用内存在浏览历史（`history.state.idx > 0`）时正常后退。
  2. 直接打开深链无应用内历史时，优先回退至能确认的上级（相册 → 所属文件夹，文件夹 → 上级文件夹，漫画卷阅读器 → 所属作品，照片阅读器 → 所属相册墙）。
  3. 上级不明时回退至当前工作台结构入口（`/photo/library` 或 `/comic/library`），且兜底跳转使用 `replace` 避免形成返回死循环。

## 8. 开放问题

以下为当前已识别但尚未定案的产品问题，统一在此维护：

- **手动标签与自建合集**：当前标签仅解析自目录名 `[方括号]`；是否引入独立于磁盘目录的手动打标与自建合集，需结合「媒体目录只读」与用户状态迁移策略评估。
- **标签入口层级**：当前标签可通过相册页视图筛选与命令面板 `#` / 名称搜索进入，是否需要在目录树旁增加固定入口待定。
- **自动文件监听在大目录树下的开销**：实时监听、10,000 目录句柄上限与 30 分钟定期校验的平衡需在超大规模目录树下持续观察。
- **人物聚类与相似分组的真实标注评测**：仓库不包含带真实照片的人工标注集，跨年龄、遮挡、逆光与大幅裁切边界的准确率仍需基于本机标注工作台持续校准。
- **离线安装（PWA）**：当前未提供 Web Manifest 与 Service Worker，浏览器离线缓存与本地媒体失效策略尚未立项。
