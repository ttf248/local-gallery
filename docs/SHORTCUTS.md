# 快捷键文档

单一来源：`frontend/src/utils/shortcuts.ts`。
按 `Ctrl+/` 启动帮助浮层查看完整列表。

## 全局

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+O` | 打开/切换图像目录 |
| `Ctrl+S` | 启动扫描 |
| `F5` | 刷新 |
| `Ctrl+H` | 回到主页 |
| `Ctrl+R` | 最近访问 |
| `Ctrl+D` | 我的收藏 |
| `Ctrl+,` | 设置 |
| `Ctrl+/` | 显示快捷键帮助 |

## 图片查看器

### 翻页 / 定位
| 快捷键 | 功能 |
|--------|------|
| `←` / `→` | 上一张 / 下一张 |
| `PageUp` / `PageDown` | 上一张 / 下一张 |
| `Home` / `End` | 第一张 / 最后一张 |
| `G` | 跳到指定页（输入页码 + 回车） |
| 拖拽底部进度条 | 跳到指定页（拖拽时浮出 5 张缩略图条） |

### 切换上下本（按上下文列表走）
| 快捷键 | 功能 |
|--------|------|
| `N` | 下一本：从主页 / 收藏 / 标签 / 集合页点开后，按列表顺序跳到下一卷 |
| `P` | 上一本：按列表顺序回到上一卷 |

### 收藏
| 快捷键 | 功能 |
|--------|------|
| `S` | 收藏 / 取消收藏（与主页右键一致） |

### 显示模式
| 快捷键 | 功能 |
|--------|------|
| `1` | 单张模式 |
| `2` | 连续滚动模式（滚轮 / 触摸滑动） |
| `3` | 双张并排（按 `L` 切换左→右 / 右→左） |

### 图片适配
| 快捷键 | 功能 |
|--------|------|
| `F` | 适配循环：适应 → 按宽 → 按高 → 原始 |
| `L` | 翻页方向（仅双张并排模式生效：左→右 / 右→左） |

### 缩放 / 变换
| 快捷键 | 功能 |
|--------|------|
| `+` / `=` / `-` | 放大 / 缩小 |
| `0` | 实际大小（100%） |
| `R` | 旋转 90° |
| `F11` | 全屏切换 |
| `Space` | 幻灯片播放 / 暂停 |
| `I` | 切换图片信息面板 |
| `Esc` | 退出全屏 → 关闭信息面板 → 关闭帮助 → 返回上一页 |

## 实现说明

- 输入框（input/textarea/contentEditable）获得焦点时自动失效，避免与中文输入法冲突。
- `useKeyboard(handlers)` hook 接受以 `combo` 为键的对象，`combo` 通过 `normalizeKey()` 规范化（小写 + `+` 分隔）。
- 查看器内部快捷键在 `Viewer.tsx` 中独立注册，避免与全局冲突。
