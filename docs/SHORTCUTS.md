# 快捷键文档

单一来源：`frontend/src/utils/shortcuts.ts`。
按 `Ctrl+/` 启动帮助浮层查看完整列表。

## 全局

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+O` | 打开/切换漫画目录 |
| `Ctrl+S` | 启动扫描 |
| `F5` | 刷新 |
| `Ctrl+H` | 回到主页 |
| `Ctrl+R` | 最近访问 |
| `Ctrl+D` | 我的收藏 |
| `Ctrl+,` | 设置 |
| `Ctrl+/` | 显示快捷键帮助 |

## 图片查看器

| 快捷键 | 功能 |
|--------|------|
| `←` / `→` | 上一张 / 下一张 |
| `Home` / `End` | 第一张 / 最后一张 |
| `+` / `-` | 放大 / 缩小 |
| `0` | 实际大小（100%） |
| `R` | 旋转 90° |
| `F11` | 全屏切换 |
| `Esc` | 退出全屏 → 关闭信息面板 → 关闭帮助 → 返回上一页 |
| `Space` | 幻灯片播放 / 暂停 |
| `I` | 切换图片信息面板 |

## 实现说明

- 输入框（input/textarea/contentEditable）获得焦点时自动失效，避免与中文输入法冲突。
- `useKeyboard(handlers)` hook 接受以 `combo` 为键的对象，`combo` 通过 `normalizeKey()` 规范化（小写 + `+` 分隔）。
- 查看器内部快捷键在 `Viewer.tsx` 中独立注册，避免与全局冲突。
