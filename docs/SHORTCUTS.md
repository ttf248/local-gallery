# 快捷键与键盘操作说明

本文件是用户可见快捷键与键盘交互行为的完整清单。全局与媒体快捷键的单一代码来源为 [`frontend/src/utils/shortcutsTable.ts`](../frontend/src/utils/shortcutsTable.ts)（清单）与 [`frontend/src/utils/shortcuts.ts`](../frontend/src/utils/shortcuts.ts)（按键匹配）；控件内部键盘操作由对应组件直接处理。

在应用任意非输入区域按 `?` 即可打开可搜索的「快捷键帮助」浮层，仅展示当前场景生效的快捷键。

---

## 1. 优先级与匹配规则

- **输入控件优先**：焦点位于 `input`、`textarea`、`select` 或 `contentEditable`（含子元素）内时，按键交由控件处理；焦点在按钮、链接或折叠摘要（`<summary>`）上时，`Space` 与 `Enter` 不触发页面级快捷键。
- **事件与输入法保护**：事件已被 `preventDefault()` 或处于中文输入法组合（IME composition）期间时，快捷键处理器跳过该事件；同一按键事件只由首个匹配处理器接管。
- **修饰键隔离**：未声明修饰键的单键快捷键（如视频控制、页码跳转 `G`）不会拦截带 `Ctrl` / `Alt` / `Meta` 的组合（例如 `Ctrl+G` 不会触发跳页）；显式注册的 `Ctrl` / `Meta` 快捷键按声明生效。
- **跨键盘布局兼容**：`normalizeKey()` 将 `ctrl` / `alt` / `shift` 拼接为 `+` 分隔的标准键名；`?`、`+`、`=` 等字符忽略 `shift` 前缀，适配不同物理键盘布局。
- **上下文分组**：清单分为 `global`（主页面）、`photo`（照片墙与大图预览）、`review`（相似照片逐组审阅）、`reader`（阅读器共用）、`image`（漫画阅读器）和 `video`（视频播放器）六组。`HelpOverlay` 根据页面场景（`library` / `photo` / `image` / `video` / `review`）先过滤分组再执行关键词检索。
- **一致性校验**：修改 `SHORTCUTS` 清单后必须同步更新对应处理器注册、测试（`shortcutsTable.test.ts`）与本文件。

## 2. 全局导航与命令面板

适用于所有挂载应用外壳（侧栏 / 顶栏）的主页面；沉浸式阅读器使用[第 5 节](#5-漫画阅读器与视频播放器)的操作。

### 主页面快捷键

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| `Ctrl+B` | 折叠 / 展开桌面侧栏 | 在 240px 与 72px 宽度间切换，偏好保存在本机 |
| `Ctrl+H` | 回到照片库 / 回到漫画库 | 跳转至 `/photo` 或 `/comic`（随当前工作台） |
| `Ctrl+R` | 珍藏 · 最近浏览 / 我的 · 最近阅读 | 跳转至 `/photo/me/recents` 或 `/comic/me/recents` |
| `Ctrl+D` | 珍藏 · 收藏 / 我的 · 收藏 | 跳转至 `/photo/me/favorites` 或 `/comic/me/favorites` |
| `Ctrl+,` | 打开「设置与任务」 | 跳转至 `/settings/general` |
| `Ctrl+S` | 重新扫描媒体库 | 已有活动扫描、或进度连接中断且结果待确认时不重复启动 |
| `/` | 打开命令面板 | 仅在非输入、非沉浸场景生效 |
| `Ctrl+K` / `⌘K` | 打开命令面板 | 全局可用，`Esc` 关闭并归还焦点 |
| `Ctrl+\` / `⌘\` | 切换目录抽屉 | 在相册页（`/photo/library`）或书架页（`/comic/library`）生效 |
| `R` | 随机翻翻（照片）/ 随机一卷（漫画） | 在图片阅读器与大图预览中用于顺时针旋转 90° |
| `U` | 打开待读漫画页（`/comic/unread`） | **仅漫画工作台生效**，照片模式下不跳转且不在帮助中显示 |
| `?` | 打开快捷键帮助浮层 | — |
| `Esc` | 关闭当前浮层 | 按最顶层模态 / 浮层顺序逐层关闭 |

> 工作台切换（照片 ↔ 漫画）不绑定全局快捷键，以避免与浏览器开发者工具或打印快捷键冲突；可通过桌面侧栏顶部切换器、窄屏「更多」抽屉或设置页切换。

### 命令面板键盘操作

桌面侧栏搜索按钮、窄屏顶栏搜索按钮、发现页搜索入口及 `/`、`Ctrl+K` / `⌘K` 均打开同一个命令面板：

- 输入前可直接选择快捷导航、按工作台保存的最近 8 条搜索记录或展开快捷操作；输入 `>` 进入命令模式，输入 `#` 按标签筛选。
- `↑` / `↓`：在建议项间循环移动；`Tab` 在输入框、检索范围（名称 / 画面与文字）、关闭按钮及空查询时的快捷操作之间切换。
- `Enter`：打开当前选中的建议项；未选中时，名称模式若存在完全同名建议则直接打开，否则进入搜索结果页；画面与文字模式直接提交至 `/photo/search?q=…&scope=content`。
- `Shift+Enter`：名称模式下直接查看全部搜索结果。
- `Esc`：有查询文本时先清空输入，再次按下则关闭面板并将焦点归还触发源。

## 3. 照片墙、大图预览与并排对比

适用于照片时间线（`/photo`）、相册照片墙（`/photo/albums/:id`）、精选照片、发现各详情页及搜索内容结果页。

### 照片墙操作

| 按键 / 操作 | 功能 |
| --- | --- |
| `[` / `]` | 调整照片墙密度（更密 / 更松），重排后保持原视口中心照片位置 |
| 点击图片 / 视频 | 打开沉浸式大图预览（视频在大图预览中直接播放） |
| 悬停照片左上角圆圈 | 加入 / 移出单张照片精选 |
| 页头多选按钮 / 点击选择圈 | 进入多选模式并勾选 / 取消勾选照片 |
| `Shift` + 点击选择圈 | 从上次选择位置连续勾选（单次上限 2,000 张） |
| `Ctrl+A` / `⌘A` | 在多选模式下全选当前已加载照片 |
| 多选操作条「并排对比」 | 恰好勾选 2 张图片时打开并排对比 |
| `Esc` | 退出多选模式（大图预览或并排对比打开时优先关闭顶层浮层） |

### 大图预览快捷键

| 快捷键 / 操作 | 功能 |
| --- | --- |
| `←` / `→` | 上一张 / 下一张（触控支持左右滑动） |
| `Home` / `End` | 第一张 / 最后一张 |
| `+` / `=` / `-` | 放大 / 缩小（支持鼠标滚轮以光标为中心缩放） |
| `0` | 恢复适应屏幕 |
| 双击画面 / 拖拽 | 以点击处为中心在适应屏幕与 200% 间切换 / 放大后拖拽平移 |
| `R` | 顺时针旋转 90° |
| `S` | 播放 / 暂停幻灯片（默认每 4 秒切换，可在选项中调整间隔） |
| `F` | 切换全屏 |
| `I` | 切换拍摄信息与详情面板 |
| `P` | 加入 / 移出精选照片（照片级，与相册收藏独立） |
| `C` | 钉入并排对比 / 与已钉入照片并排打开 |
| `Esc` | 关闭预览并回到照片墙原位，焦点归还打开的照片 |

> 当并排对比叠在大图预览之上打开时，`Esc` 与方向键由对比层独占，不会穿透触发底层预览翻页。

## 4. 相似照片逐组审阅

适用于相似照片与连拍整理页（`/photo/similarity`），当焦点位于分组列表或审阅舞台内时生效：

| 快捷键 | 功能 |
| --- | --- |
| `J` / `↓` | 下一组 |
| `K` / `↑` | 上一组 |
| `←` / `→` | 切换当前组内的聚焦成员照片 |
| `1` – `9` | 将对应序号成员设为本组代表照片 |
| `Enter` / `E` | 标记当前组为「已处理」（焦点落在单张照片本身时 `Enter` 打开大图预览） |
| `X` | 忽略当前组 |
| `P` | 将当前聚焦照片加入精选 |
| `Space` | 勾选 / 取消勾选当前组（用于批量操作） |
| `Ctrl+Z` / `⌘Z` | 撤销最近一次审阅决定（按各组操作前原状态精确恢复） |
| `Esc` | 有勾选时先清空勾选，否则返回列表 |

## 5. 漫画阅读器与视频播放器

漫画卷直接进入沉浸式阅读器（`/comic/read/:albumId`），视频通过 `/comic/read/:albumId?type=video&index=<n>` 进入。

### 阅读器共用快捷键

跨卷切换依赖进入阅读器时的列表上下文，或在无上下文时自动回退至同一作品内的兄弟卷（到首尾即停，不环绕）。

| 快捷键 | 功能 |
| --- | --- |
| `?` / `Ctrl+/` | 显示快捷键帮助 |
| `N` / `P` | 切至下一卷 / 上一卷（无对应类型媒体时自动跳过） |
| `S` | 收藏 / 取消收藏当前卷 |
| `U` | 将当前页或当前视频设为封面 |
| `Shift+U` | 清除当前卷的自定义封面 |
| `F11` | 切换全屏 |
| `Esc` | 优先关闭帮助、抽屉或信息面板；无浮层且媒体就绪时返回上一页 |

### 漫画图片阅读

#### 翻页与定位

| 快捷键 / 操作 | 功能 |
| --- | --- |
| `←` / `→`、`PageUp` / `PageDown` | 上一页 / 下一页（固定映射，不随阅读方向翻转；连续模式滚动视口高度的 90%） |
| `Space` | 按当前阅读顺序前进（连续模式到达卷末时按偏好提示或切至下一话） |
| `Home` / `End` | 第一页 / 最后一页 |
| `G` | 聚焦页码跳转框（输入页码后按 `Enter` 确认） |
| 拖拽底部进度条 | 预览 5 张缩略图并快速定位；进度条聚焦后支持 `←` / `→` / `Home` / `End` |
| 点击画面左右 1/3 / 触摸横滑 | 随阅读方向（LTR / RTL）触发上一页或下一页；画面缩放或拖拽时禁用 |
| 点击画面中央 / `H` | 显示或隐藏顶底工具栏 |

#### 显示模式、适配与工具

| 快捷键 | 功能 |
| --- | --- |
| `1` / `2` / `3` | 切换显示模式：单页 / 连续滚动 / 双页并排 |
| `F` | 循环切换适配方式：整页 → 按宽 → 按高 → 原始像素 |
| `L` | 切换翻页方向与双页排列顺序（左→右 / 右→左） |
| `O` | 双页模式下切换首张封面单页偏移（宽跨页图始终单页显示） |
| `+` / `=` / `-` | 放大 / 缩小 |
| `0` | 重置当前适配倍率至 100% |
| `R` | 顺时针旋转 90° |
| `C` | 切换章节目录抽屉（支持搜索、筛选与跨话跳转） |
| `T` | 切换页码缩略图抽屉（抽屉内用方向键移动、`Enter` 跳转、`T` / `Esc` 关闭） |
| `I` | 切换图片信息面板（路径、尺寸、格式、大小、修改时间） |

### 视频播放器

原生 `<video controls>` 之上叠加下列快捷键（视频模式下不响应漫画显示模式、适配、方向、缩放、旋转与信息快捷键）：

| 快捷键 | 功能 |
| --- | --- |
| `Space` / `K` | 播放 / 暂停 |
| `←` / `→` | 倒退 / 快进 5 秒 |
| `↑` / `↓` | 音量增加 / 降低 10% |
| `M` | 静音 / 取消静音 |
| `PageUp` / `PageDown` | 上一个 / 下一个视频 |
| `Home` / `End` | 第一个 / 最后一个视频 |

> 视频仍在加载或加载失败时，`Esc` 不触发返回页面，避免误退出正在缓冲或重试的播放界面。

## 6. 足迹页与通用控件键盘操作

### 足迹页（`/photo/travels`）

足迹页提供时间轴、地图范围与行程目录三处键盘交互（右侧小型只读地图本身不进入 Tab 序列）：

- **时间轴**：
  - `Tab`：在跨度单选（`1年 / 3年 / 5年 / 10年 / 全部`，左右键切换）、起止滑块抓手（`role="slider"`）与行程钉之间移动。
  - 抓手聚焦时：`←` / `→` 移动 1 个月，`Shift` + `←` / `→` 移动 1 年，`Home` / `End` 移至两端，`Esc` 清空选中区间。
  - 行程钉聚焦时：`Enter` / `Space` 选中对应行程。
- **地图范围**：`有数据` / `完整地图` 二选一控件支持左右方向键切换。
- **行程目录与地点详情**：`Tab` 在行程卡、照片带与「看这 N 张」之间移动；`Enter` / `Space` 展开或收起行程与到访记录，照片带及地点链按钮用 `Enter` 打开大图或地点详情。

### 页签、浮层与弹窗

- **路由页签（「设置与任务」四分区）**：普通导航链接，使用 `Tab` / `Shift+Tab` 聚焦、`Enter` 切换，受浏览器前进/后退控制；局部 `tablist` 控件支持方向键与 `Home` / `End` 切换。
- **快捷键帮助浮层**：打开自动聚焦搜索框；`Tab` / `Shift+Tab` 在关闭按钮、搜索框与清除按钮间循环；`Esc` 关闭并归还焦点。
- **弹出菜单（更多菜单、右键菜单、主题菜单）**：打开自动聚焦首个可用项；`↑` / `↓` 跳过禁用项循环，`Home` / `End` 定位首尾，`Enter` / `Space` 执行（主题菜单确认后保持打开以便连续切换），`Esc` 关闭并归还焦点，`Tab` 离开自动关闭。
- **列表排序控件**：排序按钮按 `Enter` / `Space` 展开选项；选项上按 `Enter` / `Space` 应用并返回按钮，`Esc` 取消展开。
- **属性弹窗**：模态焦点陷阱，`Tab` / `Shift+Tab` 在弹窗内循环，`Esc` 关闭并将焦点归还触发卡片或照片。

### 设置页目录输入与选择

- **路径输入框**：缓存目录与静态目录输入框按 `Enter` 确认保存（或重试失败输入），按 `Esc` 撤销草稿与失败状态；媒体根列表按 `Esc` 撤销整组根目录草稿与空槽位。中文输入法组合期间暂停自动保存，且 `Enter` / `Esc` 仅交由输入法处理。
- **本地目录选择弹窗**：路径框按 `Enter` 前往目标目录，文件夹项按 `Enter` / `Space` 下钻，`Tab` / `Shift+Tab` 在弹窗内循环，`Esc` 取消并将焦点归还「选择本地目录」按钮。
