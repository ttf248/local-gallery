# 快捷键文档

单一来源：`frontend/src/utils/shortcuts.ts`。
按 `Ctrl+/` 启动帮助浮层查看完整列表。

## 全局

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 启动扫描 |
| `Ctrl+H` | 回到主页 |
| `Ctrl+R` | 最近访问 |
| `Ctrl+D` | 我的收藏 |
| `Ctrl+,` | 设置 |
| `Ctrl+B` | 折叠/展开侧边栏 |
| `/` | 聚焦搜索框 |
| `R` | 随机一本（仅非查看器） |
| `?` | 显示快捷键帮助 |
| `Esc` | 关闭浮层 / 退出查看器 |

## 图片查看器

### 翻页 / 定位
| 快捷键 | 功能 |
|--------|------|
| `←` / `→` | 上一张 / 下一张（连续模式改为滚一屏） |
| `PageUp` / `PageDown` | 上一张 / 下一张（同上） |
| `Home` / `End` | 第一张 / 最后一张（连续模式直接滚动到首/尾图片） |
| `G` | 跳到指定页（输入页码 + 回车） |
| 拖拽底部进度条 | 跳到指定页（拖拽时浮出 5 张缩略图条） |
| 点击图片 | 左 1/3 区上一张 / 右 1/3 区下一张（中段不响应避免误触；缩放或拖拽时失效） |

### 切换上下本（按上下文列表走）
| 快捷键 | 功能 |
|--------|------|
| `N` | 下一本：从主页 / 收藏 / 标签 / 集合页点开后，按列表顺序跳到下一卷 |
| `P` | 上一本：按列表顺序回到上一卷 |

### 收藏
| 快捷键 | 功能 |
|--------|------|
| `S` | 收藏 / 取消收藏（与主页右键一致） |

### 显示模式
| 快捷键 | 功能 |
|--------|------|
| `1` | 单张模式 |
| `2` | 连续滚动模式（滚轮 / 触摸滑动） |
| `3` | 双张并排（按 `L` 切换左→右 / 右→左） |

### 图片适配
| 快捷键 | 功能 |
|--------|------|
| `F` | 适配循环：适应 → 按宽 → 按高 → 原始 |
| `L` | 翻页方向（仅双张并排模式生效：左→右 / 右→左） |

### 缩放 / 变换
| 快捷键 | 功能 |
|--------|------|
| `+` / `=` / `-` | 放大 / 缩小 |
| `0` | 实际大小（100%） |
| `R` | 旋转 90° |
| `F11` | 全屏切换 |
| `Space` | 幻灯片播放 / 暂停 |
| `I` | 切换图片信息面板 |
| `Esc` | 退出全屏 → 关闭信息面板 → 关闭帮助 → 返回上一页 |

## 视频查看器

`/viewer?type=video&path=<album>&index=<n>` 进入视频播放器。原生 `<video controls>` 已自带控制条；下方快捷键为增强项。

| 快捷键 | 功能 |
|--------|------|
| `Space` / `K` | 播放 / 暂停 |
| `←` / `→` | 倒退 / 快进 5 秒 |
| `↑` / `↓` | 音量 ±10% |
| `M` | 静音 / 取消静音 |
| `Esc` | 返回上一页（与图片查看器一致） |
| `F11` | 全屏切换 |

## 实现说明

- 输入框（input/textarea/contentEditable）获得焦点时自动失效，避免与中文输入法冲突。
- `useKeyboard(handlers)` hook 接受以 `combo` 为键的对象，`combo` 通过 `normalizeKey()` 规范化（小写 + `+` 分隔）。
- 查看器内部快捷键在 `Viewer.tsx` 中独立注册，避免与全局冲突。
