# Windows 便携包第三方组件声明

本文件说明 `local-gallery-v2.x.y-windows-amd64-portable.zip` 随包分发的第三方运行时、工具及模型权重来源与许可信息（由 [`bundle.py`](./bundle.py) 在打包时校验 SHA-256 后装配）。

## 内置组件

| 组件 | 版本 / 来源 | 许可与说明 |
| --- | --- | --- |
| Python 运行时 | [Python Build Standalone 20261124](https://github.com/astral-sh/python-build-standalone/releases/tag/20261124)（CPython 3.11.18 x86_64） | Python 及所安装 Python 软件包许可随运行时与各包分发 |
| Visual C++ 运行库 | Microsoft Visual Studio 2022 x64 CRT（`14.44.17.14`） | 随 Python 运行时以[应用本地部署](https://learn.microsoft.com/cpp/windows/redistributing-visual-cpp-files)方式提供 |
| FFmpeg / ffprobe | [Gyan FFmpeg 8.1.1 Essentials](https://github.com/GyanD/codexffmpeg/releases/tag/8.1.1) | GPL 许可与构建信息见包内 `ffmpeg/` 目录；上游提供[源码](https://github.com/FFmpeg/FFmpeg/tree/239f2c733d)与[第三方库清单](https://www.gyan.dev/ffmpeg/builds/#libraries) |
| Chinese-CLIP ViT-B/16 | [OFA-Sys/Chinese-CLIP](https://github.com/OFA-Sys/Chinese-CLIP) | MIT 许可，版权声明见包内 `Chinese-CLIP-LICENSE.txt` |
| YuNet 人脸检测 | [OpenCV Zoo · face_detection_yunet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) | 版权归 Shiqi Yu，MIT 许可，见包内 `YuNet-LICENSE.txt` |
| SFace 人脸特征 | [OpenCV Zoo · face_recognition_sface](https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface) | Apache-2.0 许可，见包内 `SFace-LICENSE.txt` |
| RapidOCR / PaddleOCR 权重 | [RapidAI/RapidOCR v3.10.0](https://github.com/RapidAI/RapidOCR/releases/tag/v3.10.0)（PP-OCRv6 检测/识别 + PP-OCRv4 方向分类） | 权重源自 PaddleOCR，版权归百度及相关权利人，Apache-2.0 许可；许可与 SHA-256 明细见包内 `RapidOCR-LICENSE.txt` 与 `RapidOCR-模型声明.md` |

## 按需下载的扩展模型

以下模型不随基础便携包直接分发，用户可按需运行包内 `download-extra-models.bat` 从各自上游下载并校验：

- **Buffalo_m**（SCRFD 2.5G + ResNet50 512 维人脸模型）：上游使用条件限于非商业研究。
- **Aesthetic Predictor V2.5**（相册 / 漫画封面审美模型）：ONNX 权重来自第三方转换分发。
