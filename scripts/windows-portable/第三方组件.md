# Windows 便携包第三方组件

- Python 运行时来自 [Python Build Standalone 20261124](https://github.com/astral-sh/python-build-standalone/releases/tag/20261124)。Python 及 Python 库的许可随运行时和各软件包分发。
- Visual C++ 运行库采用 Microsoft Visual Studio 2022 的 x64 可再分发 CRT，随 Python 以 [应用本地部署](https://learn.microsoft.com/cpp/windows/redistributing-visual-cpp-files) 的方式提供。
- FFmpeg 和 ffprobe 来自 [Gyan FFmpeg 8.1.1 Essentials](https://github.com/GyanD/codexffmpeg/releases/tag/8.1.1)。GPL 许可和构建信息见 `ffmpeg/`，对应的 [FFmpeg 源码](https://github.com/FFmpeg/FFmpeg/tree/239f2c733d) 和 [构建所用第三方库](https://www.gyan.dev/ffmpeg/builds/#libraries) 由上游提供。
- Chinese-CLIP ViT-B/16 来自 [OFA-Sys](https://github.com/OFA-Sys/Chinese-CLIP)，许可和版权声明见 `Chinese-CLIP-LICENSE.txt`。
- YuNet 来自 [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)，版权归 Shiqi Yu，采用 MIT 许可。SFace 来自 [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface)，采用 Apache-2.0 许可。
- OCR 权重来自 PaddleOCR，由 RapidOCR 转换并分发。版权归百度及相关权利人，采用 Apache-2.0 许可，权重来源、归属及 SHA256 见 `RapidOCR-模型声明.md`。

Buffalo_m 的上游使用条件限于非商业研究，相册封面 ONNX 来自第三方转换。需要时可运行 `download-extra-models.bat` 从各自上游下载并校验。
