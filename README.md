## 🐛 故障排除

### 常见问题

**Q: 扫描不到漫画？**
A: 检查文件夹权限，确保有读取权限；确认图片格式在支持列表中。

**Q: 中文路径乱码？**
A: 确保系统支持UTF-8编码，最新版本已完美支持Unicode。

**Q: 快捷键不生效？**
A: 检查是否与其他软件冲突，可在设置中自定义快捷键。

**Q: 图片加载慢？**
A: 调整图片缓存大小设置，启用预加载下一张图片。
